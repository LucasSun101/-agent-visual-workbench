# 安全边界

- **凭据不进内核、不落盘成明文**：主密钥生成后只在内存里派生出运行令牌；访问密钥只存哈希；
  插件（GitHub、webhook 等）的密钥放 `secrets.env` 或规则外的配置，由各自的插件持有。
- **中台不向外发请求**：内核没有对外网络调用，所有联网都发生在插件里，内核保持确定性。
- **指令数据分离（防 Prompt 注入）**：外部文字（Issue 正文、用户反馈）只进资料文件，
  不拼进提示词；提示词里只有校验过字符的类型、编号和链接。
  事件里带的 `cwd`、`agent`、`access` 字段被直接拒收——用哪个 Agent、在哪个目录、什么权限，只由本机规则决定。
- **跳数熔断**：Agent 交回的事件再派给 Agent，层数累加、经过提问和复查不清零、Agent 改不了；
  超过 8 层只记录不再派发。
- **重试幂等**：同一事件同 id 只记一次；同一执行交回两次只生效一次；网络断了重发不重做。
- **运行令牌**：派给 Agent 的令牌只对那一轮、那一刻有效，凭据由主密钥 HMAC 派生。
- **命令注入**：`use: "command"` 的命令数组作为独立参数传给程序，`{prompt}` 不会被当成 shell 代码执行。
- **绝不在接单电脑上执行外部代码**：事件、Issue、反馈里的内容只是资料，不会运行。

## 如果中台被用来对外提供服务

中台直接调用本机已登录的命令行工具，模型消耗算在自己账号名下，遵循各家模型厂商的服务条款。
高频自动化场景建议使用 API Key（个人订阅额度主要为日常人工交互设计）。
本项目为独立开源项目，与 Claude、OpenAI 等厂商无隶属或背书关系。
